# ADR-0003 — Visual styling approved, UX rejected

> **Status:** ACTIVE<br>
> **Authority:** ROUNDVEIL project decisions<br>
> **Product:** ROUNDVEIL — Windows + Android via Flutter/Dart<br>
> **Rule:** This file must not be used to revive removed features or to treat rejected prototype UX as approved.

- **Status:** ACCEPTED BOUNDARY / UX REMAINS BLOCKED
- **Decision date:** 2026-10-09

## Context
The user liked the visual appearance of the Felix-inspired and Overwatch-inspired HTML designs but strongly rejected their navigation, gameplay design, game-type placement and session UX.

## Decision
Use their **color, typography attitude, textures, components and overall art direction** as visual references only. Screenshots and source HTML must not be read as functional specifications. The actual ROUNDVEIL UX must be redesigned and separately approved.

## Consequences
Maintain reusable themed visual components while blocking production flow implementation where no approved UX contract exists. Preserve reference screenshots with prominent disclaimers. Avoid claiming completion from old sample interactions.
