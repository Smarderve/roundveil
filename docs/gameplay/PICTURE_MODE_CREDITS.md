# Guess the Character — Picture Mode image credits

This file is the readable attribution companion to
[`manifest.json`](../../assets/brand/character_pictures/manifest.json). Every
bundled image has a stable manifest record with its exact source page, license,
creator, pixel dimensions, and SHA-256 digest. Image files remain local and
offline in the app; no image is uploaded by Picture Mode.

The files are bundled as received from their source locations; ROUNDVEIL has
not added crops, filters, or retouching. Commons file pages are linked below so
the underlying work and current license metadata can be checked. CC BY images
require attribution; CC BY-SA images carry ShareAlike obligations for adapted
copies. Public-domain photos are credited as a courtesy. The image license
applies to the image, not ROUNDVEIL's software.

## Inventory and content boundaries

The manifest contains **50 unique bundled identities**: 17 Indian actors and
actresses, 10 footballers, 14 Hollywood actors, 8 historical presidents, and 1
professional wrestler/entertainer. Actor portraits identify the actor; movie
and series roles are contextual clues only. No Marvel, DC, Disney/DreamWorks,
cartoon, or anime character artwork is claimed in this 50-item count. These
franchise collections remain pending rights-cleared assets or owner-supplied
private packs.
