# Open Images follow-up batch — 2026-10-18

Added eight distinct object-photo challenges to the existing offline Object Name and Object Picture catalogs: apple, candle, light bulb, suitcase, sunglasses, door, coin, and watermelon. Each photo is bundled locally, decoded by the content test, and has an individual source, author/title, license, dataset image ID, dimensions, and SHA-256 entry in the object manifest and credits.

The selected photos came from the existing Open Images V7 validation working set. Open Images is a discovery/indexing dataset, not a blanket image license; the metadata records each original photo's CC BY 2.0 attribution and source URL. Excluded reviewed candidates were not added when the depicted subject was ambiguous or mismatched.

Verified repository totals after this batch: 108 Object Name challenges and 86 Object Picture images. The original 22 picture gaps remain; this batch does not claim the 500-object target is complete.

`android_home.png` is a real emulator capture after installing and launching the debug APK. It verifies app startup only, not an end-to-end match for these eight new subjects. `object_followup_contact_sheet.jpg` is a source-review contact sheet, not a gameplay screenshot.
