# Chinese actor portrait batch — 2026-10-18

Four individual, high-resolution portraits were added to the bundled Picture Mode manifest: Jackie Chan, Jet Li, Donnie Yen, and Chow Yun-fat. The images are original Commons files, not generated or substituted faces. Each manifest record includes identity, category, aliases, contextual clue, original source, license/attribution, dimensions, and SHA-256; `CREDITS.md` records human-readable attribution and ShareAlike notices.

All four local images decode at source dimensions. The manifest count is now 54 entries total, but this does not mean all legacy portraits are available in every existing profile: persisted exclusions remain in effect. The four newly approved entries are eligible for new installations and for existing installations that accept the updated content.

Jet Li's source is an event photograph with audience visible in the foreground; it is not cropped or otherwise altered. Commons notes personality-rights considerations for some portraits; source copyright permission does not imply endorsement or a model release.
