# Object content acquisition batch — 2026-10-19

This batch integrates 51 visually reviewed, offline-decoded object images: 49 new object identities and pictures for existing Mirror and Basketball name challenges.

- Open Images V7 validation: 48 photos, with source page, creator, CC BY 2.0 license, source dataset ID, SHA-256, dimensions, and processing note per image.
- Wikimedia Commons: three photos: Dice (CC BY-SA 4.0), Camping tent (CC0 1.0), and Necklace (Metropolitan Museum Open Access CC0 1.0). The transformed Dice image is distributed under CC BY-SA 4.0.
- Rejected candidates are not included in the playable manifest.
- One Open Images row originally labelled “Football trophy” was corrected to “Teapot”: the human-verified annotation says “Teapot” and the reviewed pixels match it, although the contributor's source title conflicts.
- Current catalog totals after integration: 157 object-name challenges and 137 image-backed Object Picture challenges. Remaining to 500/500: 343 names and 363 pictures.
- No new actor portrait was accepted in this batch. Last reported baseline: Chinese 4/5, Indian 0/20, Hollywood 0/20. Bruce Lee is not counted: the Commons result was a figure/statue, while the located film still was not accepted as an actor portrait.
- No fictional-character image was accepted in this batch: Marvel, DC, Disney, DreamWorks, Pixar, and Anime each remain 0/50 image-backed in the last confirmed count.
- Exact asset source, license, hash, dimensions, and mapping are in [manifest](../../../assets/app/objects/manifest.json); attribution is in [credits](../../../assets/app/objects/CREDITS.md).
- Automated content checks validate manifest mapping and decoding. This batch does not claim fresh Windows or Android runtime gameplay verification.
